Menambahkan atribut dari Excel kualitas data Buku Tanah ke shapefile bidang tanah. Kunci gabungnya NIB + desa + kecamatan, jadi NIB yang sama di desa berbeda tidak tertukar. Semua file diproses di browser ini dan tidak dikirim ke server.

1Masukkan data

Seret file, folder, atau ZIP ke kotak mana saja. ZIP di dalam ZIP (misalnya satu ZIP kabupaten berisi ZIP per kecamatan) dibuka otomatis. File SHP dan Excel dikenali dari ekstensinya.

Bidang tanah (SHP)

.zip, .shp + .dbf + .shx + .prj (+ .cpg), atau folder

Buku Tanah (Excel)

.xlsx, .csv, ZIP berisi Excel, atau folder. Desa dibaca dari nama file, mis. 23090101_Sekongkang Bawah_BukuTanah.xlsx

2Kunci pencocokan

Masukkan SHP untuk memilih kolom NIB, desa, dan kecamatan.

3Atribut yang ditambahkan ke SHP

Masukkan Excel Buku Tanah untuk memilih kolom.

4Hasil pencocokan

Hasil muncul otomatis setelah SHP dan Excel dimasukkan.

5Unduh

Belum ada hasil untuk diunduh.
